One contract, many voices.

The foundation layer defines structure only — scales, component primitives, semantic slots, voice knobs. It carries no brand. Each brand ships as a theme package that fills the slots. You are looking at the Taurid Capital theme; flip to contract in the toolbar to see the same page wearing nothing.
