# System

Vira > [Modules](../../README.md) > [Maps](../README.md) > System

The module registry, the build story behind a window, and the module tree itself.

`modulemap.py` is the registry (seeded in code, instance copy under
data/, refreshed weekly by a routine through a validated tool).
`modulestory.py` answers "What is this?" on any window from the registry and
the documents behind it. `moduletree.py` is the ladder of folders this file
sits in: `check` guarantees every tracked file is placed exactly once and
every README's generated block is current.

## What lives here

Everything below is generated from `module.json` and the files themselves. Scripts, assets, tests and documents that belong to this submodule are listed here even while they still sit in the shared top-level folders; see "Moving code" in the root README.
