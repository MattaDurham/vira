# Maps

Vira > [Modules](../README.md) > Maps

The System Map (this registry, live) and layered diagrams any request can fill.

Two windows. System Map renders the module registry - one record per
module, what it reads and feeds - plus the change log, so the map is only as
stale as the registry, never as stale as an exported diagram. Maps is the
same left-to-right column shape as a type any request can fill. The module
tree you are reading lives here too: `server/moduletree.py` keeps these
folders, their manifests and their READMEs in step with the code.
