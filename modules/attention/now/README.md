# Now

Vira > [Modules](../../README.md) > [Attention](../README.md) > Now

The aggregator: what Vira is doing right now and what is waiting on the owner right now.

`attention.py` reads every module that can be waiting (sessions,
routines, triage, review, the feed) and consolidates them into one list.
