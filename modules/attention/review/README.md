# Review

Vira > [Modules](../../README.md) > [Attention](../README.md) > Review

One queue for every decision waiting on the owner, and how often each standing rule breaks.

The corrections ledger's proposal pipeline used to run with no
reader; `reviewqueue` is the one place decisions wait. `lessonwatch` counts
how often each rule in the ledger actually breaks.
