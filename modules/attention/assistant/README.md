# Assistant

Vira > [Modules](../../README.md) > [Attention](../README.md) > Assistant

The standing executive: commitments, quiet reminders, desktop pins, calendar suggestions, event prep.

`executive` is the worker; `commitments` are private owner tasks from
self messages and non-contact correspondence (a known person's loops belong
to the CRM); `commitmentresources` and `assistantresources` are the source-
backed links behind them, pure parsing; `reminderstickies` pins reminders on
the desktop without a second task store; `calendarplan` makes evidence-
linked calendar suggestions where the only writer creates a tightly scoped
personal block; `eventprep` is one countdown checklist per dated event.
