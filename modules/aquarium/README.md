# Aquarium

Vira > [Modules](../README.md) > Aquarium

The desktop's living backgrounds: a metre-scaled koi pond with articulated fish, and photographic landscapes.

The background behind the desktop runs in its own document so the
desktop keeps focus and gestures. The koi are a research project of their
own - authored, source-informed mechanics (not CFD), articulated rigid-body
rendering through Three.js WebGPU, with the Blender asset pipeline under
scripts/aquarium. It is the largest single test suite in the repository.
