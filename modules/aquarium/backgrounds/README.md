# Backgrounds

Vira > [Modules](../../README.md) > [Aquarium](../README.md) > Backgrounds

The background adapter, the pond, and the photographic landscapes.

`desktop-backgrounds.js` is the adapter the desktop talks to;
`koi-pond.js` and `koi-pond-3d.js` are the pond; `static/backgrounds/` the
landscapes.
