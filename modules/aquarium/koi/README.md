# Koi

Vira > [Modules](../../README.md) > [Aquarium](../README.md) > Koi

The articulated koi: mechanics, fins, pigment, optics, the asset pipeline, and its studies.

Every `static/aquarium-*.js` file is one concern of the fish (spine,
turn, fins, caudal, pigment, water, optics, collision); `static/aquarium/`
holds the glb and the recorded studies; `scripts/aquarium/` builds the asset
in Blender. Several files carry `eol=lf` in `.gitattributes` because the
integrity checks hash their bytes.

Everything below is generated from `module.json` and the files themselves. Scripts, assets, tests and documents that belong to this submodule are listed here even while they still sit in the shared top-level folders; see "Moving code" in the root README.
