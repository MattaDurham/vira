# World

Vira > [Modules](../README.md) > World

The owner's world as a typed, temporal 3D graph: people, notes, concepts, time.

The World window draws the graph: every note, person, concept and
tag the connected vault and CRM know, laid out in semantic 3D coordinates
from the same local embeddings retrieval already keeps. The Contact Atlas is
one projection of it (faces and ties), with four lenses that band the same
web differently; Orbits is the network as time; subsets lay a slice out on
its own.
