# Atlas

Vira > [Modules](../../README.md) > [World](../README.md) > Atlas

The Contact Atlas: a face-graph of the CRM, four lenses, and the vault web joined on.

Every contact is a node rendered with their face; edges are shared
threads, groups and evidence. Lenses colour the one web four ways. The vault
web joins wiki people onto the Visual Network, so the people the owner has
met and the people the vault knows about sit in one graph.
