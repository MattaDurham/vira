# Graph

Vira > [Modules](../../README.md) > [World](../README.md) > Graph

The temporal World graph, its semantic 3D layout, subsets, and the WebGL renderer.

`worldgraph` builds the typed graph; `worldlayout` places it from the
vault's and CRM's nomic vectors; `worldsubsets` cuts a slice and lays it out
alone. `atlas3d.js` is the renderer the Visual Network draws through when
WebGL is available; `atlas.js` is the window.
