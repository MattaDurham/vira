# Image Atlas

Vira > [Modules](../README.md) > Image Atlas

The vault's images as a navigable 3D galaxy, and the Genre Studio that composes new genres.

The Image Atlas is a chaska adapter: the standalone local image-
galaxy engine, hosted inside Vira with the vault's images. It is also an
operating surface, not just a viewer - vault operations go through a
plan-and-approve gate. The Genre Studio composes a new visual genre out of
pieces of reference images and generates from it.
