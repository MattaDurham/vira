# Galaxy

Vira > [Modules](../../README.md) > [Image Atlas](../README.md) > Galaxy

The chaska adapter, its HTTP surface, the mobile view, and gated vault operations.

`imageatlas.py` is the pure adapter and `imageatlasroutes.py` its
router, kept apart so the adapter stays importable and testable. `atlasops`
is the plan-and-approve gate in front of every vault write the galaxy can
make.
