# Genres

Vira > [Modules](../../README.md) > [Image Atlas](../README.md) > Genres

The Genre Studio: compose a genre from reference pieces and generate images in it.

A genre maker, not a skin wizard (rebuilt 2026-07-27): `genrestudio`
is the pure engine, `genreroutes` its HTTP surface, `genregen` the Generate
button. `genre.html` is the standalone studio page.
