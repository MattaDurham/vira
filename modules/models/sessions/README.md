# Sessions

Vira > [Modules](../../README.md) > [Models](../README.md) > Sessions

The provider-agnostic session harness, every adapter, and Vira's native tools.

`agentbackend` is the seam; `codexapp` (Codex App Server), `grokacp`
(Grok Build over the Agent Client Protocol) and `functionagent` (Gemini and
Grok function calling) are the adapters. `viratools` is the deep Vira
connection: the native tools a child session gets, with every write going
through a validated tool (`WRITE_TOOLS`), never the agent's own hands.
`mcpbridge` hands that registry to a CLI that only takes MCP servers.
Sessions always pass `can_use_tool=runner.gate`; the gate itself is in
Work / Sessions.
