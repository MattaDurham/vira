# Models

Vira > [Modules](../README.md) > Models

Which AI backends this Mac has, how much a prompt may carry, and the harness a live session runs in.

Everything that talks to a model goes through here. The capability
probe answers "what backends does this machine actually have"; the budget
seam answers "how much may this prompt carry" (every cap says why); module
model choices route each feature's work to a chosen model; AI health is the
self-check that keeps the product survivable when model auth fails. The
session harness makes a live agent session provider-agnostic - Claude Agent
SDK, Codex App Server, Grok Build over ACP, or plain function calling - and
hands every session Vira's native tools.
