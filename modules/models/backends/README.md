# Backends

Vira > [Modules](../../README.md) > [Models](../README.md) > Backends

The capability probe, prompt budgets, per-module model choices, admission, and health.

`models.py` probes; `modelbudget.py` sizes (ask it before raising any
cap, and `tool_result_cap()` before any tool-output cap - the SDK kills a
session over a 1 MiB line); `modeladmission` reserves a cross-process slot
before execution; `modulemodels` is the per-feature choice the Config window
exposes; `suggest.complete` is a full agent, so pass `tools=READ_TOOLS`
whenever the prompt carries untrusted text; `suggest.effective_backend` is
the only answer to "which model replies".
