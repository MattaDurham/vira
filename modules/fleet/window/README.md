# Window

Vira > [Modules](../../README.md) > [Fleet](../README.md) > Window

The live Fleet window and the stream that feeds it.

`fleet.py` collects every reader's rows into one snapshot and
streams changes; `fleet.js` renders them (a re-render restarts CSS
animations, so it repaints from fresh state).
