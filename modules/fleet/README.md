# Fleet

Vira > [Modules](../README.md) > Fleet

Every Claude Code, Codex and Vira session on this machine, live, with the repositories around them.

Fleet (2026-10-20) is the window for the whole machine, not one
Vira: desktop-app sessions, terminal sessions, subagents, Codex threads from
the app, the extension and the CLI, Vira's own jobs, and the worktrees,
branches and PRs they work in - all read from the files those tools write,
never from a wrapper. Analyze is one model call, on request, that writes a
plain status for each.
