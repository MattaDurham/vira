# Setup

Vira > [Modules](../../README.md) > [Core](../README.md) > Setup

First run: the fixture demo, onboarding, module front doors, data connections, the folder picker.

A fresh clone boots into fixture mode - one contact, Vira themself.
Onboarding is the stranger's path from there to their own data: connect real
contacts, build the first dossiers, wire the Brain. A module whose config is
absent is dormant and its front door is the path to live. Data connections
inspect and connect owner stores without copying them. The folder picker is
the OS's own panel. `agentslocal` seeds and diffs the owner's private
operating file from the public template.

Everything below is generated from `module.json` and the files themselves. Scripts, assets, tests and documents that belong to this submodule are listed here even while they still sit in the shared top-level folders; see "Moving code" in the root README.
