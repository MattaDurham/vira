# Settings

Vira > [Modules](../../README.md) > [Core](../README.md) > Settings

The one table of owner settings, the Config window's forms, and the Keychain.

Every key `data/config.json` may carry is one row in
`settingschema.py` (group, type, default, label, help); `settings.DEFAULTS`,
the Config forms, `config.example.json` and the assistant's defaults are
all derived from it, and `python -m server.settingschema example --write`
regenerates the template. Writes go through `settings.save`, validated,
under the shared lock. Secrets go to the Keychain through
`settings.keychain_service()`, namespaced per instance.
