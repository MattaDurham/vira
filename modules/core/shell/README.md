# Shell

Vira > [Modules](../../README.md) > [Core](../README.md) > Shell

The FastAPI app and the single-page desktop: windows, palette, deep links, UI state.

`main.py` declares every `@app` route and mounts every router; it is
5,700 lines because every module's HTTP surface still lives in it (moving
each module's routes into its own router is the first step of gathering a
module, see modules/README.md). `app.js`, `index.html` and `style.css` are
the desktop: the `WINDOWS` table every window is one entry in, the aliases
that keep retired window ids working, `HASH_ROUTES` for deep links, and the
shared helpers (`lsGet`, `startPoll`, `bindSheet`, `cardAction`). UI state
is persisted server-side so a saved layout follows the owner. The omni
router is rung 2 of the dictation door.
