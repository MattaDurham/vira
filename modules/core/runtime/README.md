# Runtime

Vira > [Modules](../../README.md) > [Core](../README.md) > Runtime

Admission control, locks and stores, backups, restart, update, workers, and the stall detector.

The process discipline. Every route is a sync def sharing one GIL
with the event loop, so CPU-heavy work goes through `admission.cpu()`.
Small JSON stores go through `jsonstore` under the cross-process `filelock`.
Non-regenerable stores join `backup.FILES`. `instance` gives each checkout
its own identity and ports; `restart` is the cancellable server-owned
restart queue and `runtimework` what it must drain first; `update` pulls
and restarts; `loopwatch` is the event-loop stall detector; `workers` is one
row per background worker. The Windows CI job is the only Windows machine,
and the portability tests live here.
