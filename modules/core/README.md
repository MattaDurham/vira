# Core

Vira > [Modules](../README.md) > Core

The shell, the runtime, settings, and first-run setup that every other module stands on.

Nothing in Core is a feature. It is the app shell (`main.py` and
`app.js`, the desktop of floating windows, the command palette, the omni
router), the process runtime (admission control, file locks, JSON stores,
backups, the restart queue, the in-app updater, the stall detector), the one
table of settings every config key is a row in, and the stranger's path from
the fixture demo to their own data. When a rule in `AGENTS.local.md` section
5 says "every X goes through Y", Y is usually here.
