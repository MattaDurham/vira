# Sessions

Vira > [Modules](../../README.md) > [Work](../README.md) > Sessions

Live agent sessions that outlive the server: launch, steer, record, judge, resume.

Every SDK job runs outside the server as its own process group
(`runner.py`), re-attached on boot, with `jobfiles` the on-disk protocol
between them and `joblog` the durable ledger every launch gets a row in.
`session.py` is the registry and the steering surface; `sessiondiag`
answers why a session stopped; `judge` grades finished work with fresh
eyes; `workresults` is the one inventory the timeline, gallery and detail
inspector read. `runner.gate` is the permission gate every session passes.
