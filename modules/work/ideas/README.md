# Ideas

Vira > [Modules](../../README.md) > [Work](../README.md) > Ideas

The backlog: Vira's own cross-session roadmap, its tags, images, and the Approve & build path.

The Queue tab. `ideas.py` is the source of truth for the roadmap;
`ideatags` makes it searchable, groupable and self-aware about repetition
(the propose gate needs an absolute similarity condition); `ideaimages`
attaches the screenshot of the bug or the mockup to build from. Approve &
build is one Implement session on its own branch.
