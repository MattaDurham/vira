# Branches

Vira > [Modules](../../README.md) > [Work](../README.md) > Branches

Branch-first enforcement, the Showroom of draft branches, orphan work, and the merge gate.

One feature = one branch = one worktree, and the live checkout only
changes at a merge. `worktree.py` enforces it for dispatched sessions;
`scripts/branch.sh` is the workflow (start, serve, pr, merge, discard) with
preflight's checks (`scripts/preflight.sh --list` names every rule and the
incident that earned it) and the PII guard in front of every commit. The
Showroom shows every draft branch as a card to test-drive and rule on; the
orphan sweeper inventories work that never landed; `prindex` asks gh once
which PR belongs to which branch.
