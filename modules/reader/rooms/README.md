# Rooms

Vira > [Modules](../../README.md) > [Reader](../README.md) > Rooms

Reading rooms, full ingest into the vault, and the nightly inflow shelf.

A room is a validated, store-native write; its items become vault
notes through `roomvault`, and `fullingest` lands each item's material in
the vault (transcript, text, stills). `ingestfeed` shows the five nightly
routines' output as one shelf. The staging script audits a TC-IL delta
before anything is written.
