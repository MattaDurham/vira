# Media

Vira > [Modules](../../README.md) > [Find](../README.md) > Media

The local index over everything ever shared: photos, documents, voice memos, links, message bodies.

Everything shared over iMessage or mail becomes searchable here:
scene embeddings (SigLIP on the Mac's GPU), OCR through Apple Vision, face
identity harvested from Apple Photos' named faces, text similarity, and
exact-text FTS5. The media archive keeps Vira's own copy of attachments,
because macOS treats the Messages attachment folder as an evictable cache.
The text index is the fourth corpus: message and mail bodies. One rule holds
the whole thing together - one SQLite build per FTS5 index, the venv's -
and `ftsguard.py` is the self-heal every index runs on open.
