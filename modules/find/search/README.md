# Search

Vira > [Modules](../../README.md) > [Find](../README.md) > Search

The sorter: which of the four corpora answers this query.

`find.py` is the router behind the box. It decides database versus
meaning, picks the corpus, and shapes the result list the window renders.
The corpora themselves belong to their submodules; this one only chooses and
asks.
