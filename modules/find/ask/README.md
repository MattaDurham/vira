# Ask

Vira > [Modules](../../README.md) > [Find](../README.md) > Ask

Grounded answering: hybrid retrieval, policy-checked local evidence, and the durable Find chat.

The answer path. Retrieval primitives (FTS query building, bm25 and
cosine ranking, reciprocal-rank fusion) are shared by every corpus. Answer
sources snapshot exactly what a reader read, versioned and policy-checked.
The answer runtime carries explicit, session-scoped model settings. Vira
chat is the durable conversation backed by the native session harness, and
the evaluation guard is the read-only handshake for a synthetic evaluation
instance.
