# Define

Vira > [Modules](../../README.md) > [Find](../README.md) > Define

Right-click any selected text: a definition card, and the Mac service that reaches it.

Select text anywhere - in Vira, or in any Mac app through the
"Define with Vira" service - and a definition opens in the Definition
window. The card is a ladder: the short answer first, deeper rungs on
request, and a path to ingest the term into the vault. The curated AI-
terminology atlas on the site is read here too.
