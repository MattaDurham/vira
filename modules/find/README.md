# Find

Vira > [Modules](../README.md) > Find

One search box over four corpora, with grounded answers and definitions.

Find sorts a typed query: is it a database question or a meaning
question, and which corpus answers it - the CRM, the vault of notes, the
media index of everything ever shared, or message and mail bodies. Search
and the one-shot Ask stay stateless; the Find chat is durable and grounded.
Right-click any selected text anywhere in Vira and a definition opens, a
ladder that erases its own rungs. Concept Cloud, Related and Definition are
companion windows of this one.
