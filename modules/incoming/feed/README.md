# Feed

Vira > [Modules](../../README.md) > [Incoming](../README.md) > Feed

The one live feed: item state, the reply channel, sends and pushes.

The feed is a merge of every connector's items with per-item state
(read, hidden) kept server-side so the phone and the desktop agree. Shared
channel mechanics live here so a new connector adds one adapter, not a copy
of the plumbing. Outbound traffic is here too: sending an approved reply
through Messages.app, choosing iMessage or SMS per person, and the pushes
Vira texts the owner on high-value inbound. The self-thread doubles as a
two-way command line.
