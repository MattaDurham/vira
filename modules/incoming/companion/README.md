# Companion

Vira > [Modules](../../README.md) > [Incoming](../README.md) > Companion

The Android companion app: pairing, message ingest, and phone pings.

The phone that is not an iPhone still reaches Vira: the Kotlin app
under android/ pairs with the server, forwards messages, and can be pinged.
The server side is one connector module; the app has its own README and CI
job.
