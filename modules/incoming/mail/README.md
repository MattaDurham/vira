# Mail

Vira > [Modules](../../README.md) > [Incoming](../README.md) > Mail

IMAP and Microsoft 365 inboxes, the local mail archive, and reading or answering an email.

Two ways in: an IMAP watcher for ordinary mailboxes and the Graph API
for Microsoft 365, where basic auth is gone (device-code or PKCE sign-in in
the local browser, codes never in URLs or logs). Every message is archived
locally with its attachments, attachments join the semantic index, and the
feed's email cards open into a small mailbox surface that can reply. Calendar
invitations that arrive as email are answered here too.
