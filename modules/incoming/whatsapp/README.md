# WhatsApp

Vira > [Modules](../../README.md) > [Incoming](../README.md) > WhatsApp

Receive-only WhatsApp through a linked-device sidecar process.

A Node sidecar (bridge/whatsapp) holds the linked-device session and
hands inbound messages to the server, which turns them into feed items joined
to CRM people. The session folder under data/ is the pairing; deleting it
unpairs the phone.
