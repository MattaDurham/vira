# iMessage

Vira > [Modules](../../README.md) > [Incoming](../README.md) > iMessage

chat.db read in place, and the watcher that tails it for new arrivals.

Vira never copies the Messages database; it reads it where macOS
keeps it (Full Disk Access granted to Vira's python) and a watcher notices
new rows. Threads, groups and attachments come from here. The durable copies
of attachments and the search index over them live in Find / Media, because
that is where they are queried; this submodule is the live read.
