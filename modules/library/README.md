# Library

Vira > [Modules](../README.md) > Library

Browse a vault by subject and read it whole; the documents Vira serves itself.

The Library window builds each vault's subject tree (areas, subjects,
notes) and lets the owner read a subject end to end, with rendered-face
thumbnails for the HTML documents. Site documents - dossiers, plans,
walkthrough pages whose only reader is the owner - are migrated into
git-ignored static/docs and served from Vira, tagged with the same vocabulary
the ideas backlog uses.
