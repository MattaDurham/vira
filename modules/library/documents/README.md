# Documents

Vira > [Modules](../../README.md) > [Library](../README.md) > Documents

Site documents served from Vira, their tags, their thumbnails, and the blog.

`sitedocs` is the migration path for owner-only documents (`python -m
server.sitedocs add`), `doctags` tags them with the ideas vocabulary,
`docthumbs` renders their faces for the grid, and `blog` keeps Vira's blog
canonical in Vira with the site as a projection.
