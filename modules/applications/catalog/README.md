# Catalog

Vira > [Modules](../../README.md) > [Applications](../README.md) > Catalog

The role catalog, the application evidence map, shared job logic, and the employer's vault page.

`applications.py` owns the role and its stable uid; `applicationmap`
maps role requirements to claim-safe material; `jobshared` is what the
catalog and the boards used to carry privately (the uid, the merge);
`companywiki` resolves the employer's page in the vault.

Everything below is generated from `module.json` and the files themselves. Scripts, assets, tests and documents that belong to this submodule are listed here even while they still sit in the shared top-level folders; see "Moving code" in the root README.
