# Boards

Vira > [Modules](../../README.md) > [Applications](../README.md) > Boards

The live job-board feed, the posting readable inside Vira, and where the work happens.

`jobboards` polls the boards into the catalog; `jobdesc` keeps the
posting readable; `workplace` reads what a posting's own body says about
where the work happens, because a board's location field is metadata an
employer did not write.
