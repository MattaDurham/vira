# Applications

Vira > [Modules](../README.md) > Applications

The job search: a merged role catalog, live boards, per-role scores, and the documents behind an application.

A merged, deduplicated role catalog the owner can star, comment on and
track; the live boards behind it; one score per role written by Vira and
re-read against today's canon; and the documents - the resume viewport that
can be read, questioned and annotated, and the markup of a hand-written draft
against a role. The employer's own vault page is resolved and measured for
each application.
