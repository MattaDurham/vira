# Scoring

Vira > [Modules](../../README.md) > [Applications](../README.md) > Scoring

One score per role, rescoring against today's canon, and deterministic comparison.

`jobscores` stores a role's judgment (fit, why, tier, lane, verdict);
`jobrescore` re-reads it against the current canon; `jobcompare` answers
two questions about two descriptions without a model call.
