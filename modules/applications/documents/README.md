# Documents

Vira > [Modules](../../README.md) > [Applications](../README.md) > Documents

The resume viewport and the markup of a hand-written draft against a role.

`resumeview` is the viewport (annotations outlive the draft they were
written against) and `resumeviewroutes` its router; `draftcheck` reads a
Word draft and marks it up against the role.
