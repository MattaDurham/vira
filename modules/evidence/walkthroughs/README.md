# Walkthroughs

Vira > [Modules](../../README.md) > [Evidence](../README.md) > Walkthroughs

The films of how each feature was built, and the anonymizer that lets them be public.

`walkthroughs.py` serves them, `scripts/walkthrough-capture.py`
records one, and `walkthrough_anon` scans every capture for personal data
before it can be committed (an on-device OCR gate on this Mac).
